# Redgate Handbook

A no-nonsense overview of all of Redgate's solution areas, for the sales and solutions teams.

- Flyway
- Monitor
- Test Data Manager (TDM)
- Toolbelt Essentials (TBE)

Plain static HTML — no backend. See [CLAUDE.md](CLAUDE.md) for how it's built and deployed.

## Quick start

```
ruby generate.rb                     # build public/ from templates + data
ruby -run -e httpd public -p 3000    # serve it locally
```
