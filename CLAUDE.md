# Redgate Handbook — Project Context

## What this is
An internal product reference site for Redgate's sales and solutions teams. Built by Nick Hape (Solutions Engineer at Redgate Software). The goal is one fast, easy place for non-technical colleagues to find key info about each product.

## Stack
Plain static HTML + Tailwind CSS, generated by a small Ruby script. No Rails, no server, no gems beyond the Ruby standard library (`erb`, `yaml`, `json`, `net/http`, `rexml`).

- Content lives in `data/products.yml` and `data/releases_data.json`.
- Templates live in `templates/*.html.erb` (layout, home, product — one shared template for every product page).
- `generate.rb` renders the templates + data into `public/` — this is the actual served site and is committed to git.
- `fetch_releases.rb` pulls the release-notes RSS feed, asks Claude to summarise it for a sales audience, and writes `data/releases_data.json`.

## Running locally
```
ruby generate.rb              # regenerate public/ from templates + data
ruby -run -e httpd public -p 3000   # serve it at http://localhost:3000 (needs `gem install webrick` once)
```
To refresh release notes locally you need `ANTHROPIC_API_KEY` set:
```
ANTHROPIC_API_KEY=... ruby fetch_releases.rb        # all products
ANTHROPIC_API_KEY=... ruby fetch_releases.rb monitor # one product
```

## Deployment
- Live at: https://redgate-handbook.onrender.com
- Render is configured as a **static site** (`render.yaml`, `runtime: static`) — it just serves `public/`, no build step, no Ruby runtime at request time.
- Auto-deploys from the `main` branch.
- A GitHub Actions workflow (`.github/workflows/update-content.yml`) runs weekly, calls `fetch_releases.rb` + `generate.rb`, and pushes the regenerated `public/` + `data/releases_data.json` straight to `main` if anything changed. It needs an `ANTHROPIC_API_KEY` repo secret to work.
- Branch strategy: short-lived feature branches, squash-merged into `main` via PR.

## Product page structure (standard across all products)
1. Header — name + tagline
2. What it does — short description
3. Supported Platforms — database logo icons (devicons CDN)
4. Key Features — tabbed cards (title, description, screenshot, points)
5. Demo Servers (Monitor only)
6. Useful Links — docs, demos, etc.
7. What's New — auto-fetched release notes, refreshed weekly

## Key files
- `data/products.yml` — all product content
- `data/releases_data.json` — cached release notes (weekly-refreshed, committed to git)
- `templates/product.html.erb` — shared product page template
- `templates/home.html.erb` — home page with product cards
- `templates/layout.html.erb` — navbar + page shell
- `generate.rb` — renders templates + data into `public/`
- `fetch_releases.rb` — fetches + summarises release notes into `data/releases_data.json`
- `assets/` — source images/CSS/icons that `generate.rb` copies into `public/`
- `render.yaml` — Render static-site config
