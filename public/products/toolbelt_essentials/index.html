Product Overview

SQL Toolbelt Essentials

The essential toolkit for SQL Server developers

What it does

SQL Toolbelt Essentials bundles Redgate's most-used SQL Server tools into one package — schema comparison, data comparison, intelligent autocomplete, and fast object search. The tools that SQL Server developers reach for every day, at a bundled price.

Supported Platforms

SQL Server

Key Features

SQL Compare

Compare and deploy SQL Server database schemas in minutes. See exactly what's different between two databases, generate a deployment script, and apply it — with a full preview before anything changes.

Schema diff

Side-by-side comparison of any two SQL Server databases, scripts, or source-control folders.

Deployment script generation

Generate a safe, ordered deployment script with a single click — or run it directly.

→ Source control integration

Compare against a scripts folder in Git to keep schema and code in sync.

SQL Data Compare

Compare and synchronise data between SQL Server databases at the row level. Find exactly which rows differ, and deploy only what's changed — ideal for keeping reference data and lookup tables in sync across environments.

Row-level diff

See insertions, updates, and deletions between any two databases.

Selective deployment

Choose exactly which rows to synchronise — you're always in control.

Backup-to-live comparison

Compare a live database against a backup to understand what changed.

SQL Prompt

Intelligent autocomplete, code formatting, and snippet management for SQL Server Management Studio and Azure Data Studio. Write SQL faster and with fewer mistakes.

Context-aware autocomplete

Suggestions that understand your schema — tables, columns, aliases, and more.

Code formatting

Instantly reformat any SQL to your team's style guide with a single shortcut.

Snippets

Save and reuse boilerplate SQL — common queries, templates, and patterns.

→ SQL Prompt for VS Code

Now available as a VS Code extension.

SQL Search

Find any database object — tables, columns, stored procedures, views — across all databases on a server in seconds. Free SSMS plugin, included in Toolbelt Essentials.

Search across all databases

One search box, every object on the server — no need to expand the object explorer one database at a time.

Find dependencies

See what references an object before you change or drop it.

→ Free download

SQL Search is also available as a standalone free tool.
