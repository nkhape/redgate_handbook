Product Overview

Redgate Flyway

Database migrations made easy

What it does

Flyway is an open-source database migration tool that lets teams version-control their schema changes alongside application code. It applies migrations in order, tracks what's been run, and integrates with any CI/CD pipeline — so your database moves with your code, every time.

Supported Platforms

SQL Server
PostgreSQL
MySQL
Oracle
MariaDB

plus 50+ more with foundational support →

Key Features

Database Version Control

Every database change is version-controlled — written down, ordered, and tracked, just like application code. No guessing what's been applied where.

Works however you want

Either way, Flyway generates the actual deployment script for you — respecting dependencies and applying changes in the right order.

Migrations-based →

Write out each change, step by step.

State-based →

Describe the end result — Flyway works out how to get there.

Ordered & tracked

Every change runs in the same order, on every environment, every time.

Undo when needed

Roll back a change cleanly instead of writing a manual fix.

CI/CD Integration

Flyway plugs straight into the pipelines your team already uses, so migrations run automatically and identically on every deploy — no manual steps, no "works on my machine."

Fits any pipeline

Installs as a simple command-line tool, so it fits into almost any build or deployment process.

Works with what you have

GitHub Actions, Jenkins, Azure DevOps, and more.

Quality Gates

Nothing reaches production without a check first.

Dry runs

See exactly what will change before it touches the database.

Automatic checks

Use pre-built checks, or add your own easily, to flag risky or non-compliant changes before they're deployed.

Sign-off required

Sensitive environments can require manual approval before going ahead.

Visibility & Reporting
