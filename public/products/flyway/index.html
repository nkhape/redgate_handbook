Product Overview

Redgate Flyway

Database migrations made easy

What it does

Flyway is an open-source database migration tool that lets teams version-control their schema changes alongside application code. It applies migrations in order, tracks what's been run, and integrates with any CI/CD pipeline — so your database moves with your code, every time.

Supported Platforms

PostgreSQL

Key Features

Database Version Control

Every database change is version-controlled — written down, ordered, and tracked, just like application code. No guessing what's been applied where.

Works however you want

Either way, Flyway generates the actual deployment script for you — respecting dependencies and applying changes in the right order.

What's New

February 5, 2026 – July 20, 2026

Over the last three months, Flyway has delivered major productivity wins including guided shadow provisioning now available to all Enterprise customers, new code review capabilities with customizable SQLFluff rules and SARIF reporting for GitHub and Azure integration, and enhanced drift detection with configurable resolution folder paths and improved error reporting. For Oracle users, there are new options like existence checks for indexes and permissions user checks for secure deployments. Database support has expanded with Databricks, Cassandra Native Connectors, and SQLite support, while performance improvements include faster startup times, lazy driver loading, and reusable Docker containers. New secret management capabilities now include Azure Key Vault integration, and the platform now supports GitHub Actions workflows for automated deployments with manual approval steps.
