Product Overview

Redgate Flyway

Database migrations made easy

What it does

Flyway is an open-source database migration tool that lets teams version-control their schema changes alongside application code. It applies migrations in order, tracks what's been run, and integrates with any CI/CD pipeline — so your database moves with your code, every time.

Supported Platforms

PostgreSQL
MySQL
Oracle
MariaDB

Key Features

Database Version Control

Every database change is version-controlled — written down, ordered, and tracked, just like application code. No guessing what's been applied where.

Works however you want

Either way, Flyway generates the actual deployment script for you — respecting dependencies and applying changes in the right order.

State-based →

Ordered & tracked

Every change runs in the same order, on every environment, every time.

Undo when needed

CI/CD Integration

Flyway plugs straight into the pipelines your team already uses, so migrations run automatically and identically on every deploy — no manual steps, no "works on my machine."

Fits any pipeline

Works with what you have

What's New

February 20, 2026 – July 30, 2026

Over the past three months, Flyway has delivered major productivity gains across database deployment workflows. Databricks support now includes both Lakebase and Lakehouse (Unity Catalog) variants for data teams working with modern analytics platforms. The drift resolution folder feature lets teams automatically organize scripts that fix schema differences, while Oracle deployment enhancements add existence checks and permission guards to prevent script failures. For PostgreSQL users, flexible filtering UI now enables precise object selection during deployments. On the automation front, GitHub Actions workflow generation streamlines CI/CD setup, and Azure Key Vault integration brings enterprise-grade secrets management to deployment pipelines.
