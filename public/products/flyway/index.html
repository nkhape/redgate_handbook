Product Overview

Redgate Flyway

Database migrations made easy

What it does

Flyway is an open-source database migration tool that lets teams version-control their schema changes alongside application code. It applies migrations in order, tracks what's been run, and integrates with any CI/CD pipeline — so your database moves with your code, every time.

Supported Platforms

PostgreSQL
MySQL
Oracle
MariaDB

Key Features

Database Version Control

Every database change is version-controlled — written down, ordered, and tracked, just like application code. No guessing what's been applied where.

Works however you want

Either way, Flyway generates the actual deployment script for you — respecting dependencies and applying changes in the right order.

What's New

March 26, 2026 – August 27, 2026

Recent releases bring powerful new capabilities for database management and deployment automation. Teams can now configure code review policies directly in Flyway Desktop, streamlining quality gates, while automated deployment workflows with manual approval steps provide better control over production changes. The platform now supports Databricks Lakebase as a distinct database type alongside improved Oracle deployment options, and native connectors mode for SQLite and Cassandra eliminates legacy JDBC dependencies. For teams using GitHub, automatic GitHub Actions workflow generation simplifies CI/CD setup, while enhanced error messaging and UI improvements make deployments more intuitive and less error-prone.
