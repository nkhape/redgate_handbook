Product Overview

Redgate Flyway

Database migrations made easy

What it does

Flyway is an open-source database migration tool that lets teams version-control their schema changes alongside application code. It applies migrations in order, tracks what's been run, and integrates with any CI/CD pipeline — so your database moves with your code, every time.

Supported Platforms

PostgreSQL

MariaDB

Key Features

Database Version Control

Every database change is version-controlled — written down, ordered, and tracked, just like application code. No guessing what's been applied where.

Works however you want

Either way, Flyway generates the actual deployment script for you — respecting dependencies and applying changes in the right order.

What's New

February 20, 2026 – July 20, 2026

Over the past three months, Flyway has delivered significant enhancements across both Desktop and CLI products, with major wins in code quality, deployment automation, and database compatibility. The new code review capabilities embedded in Desktop now catch potential SQL issues during migration generation and deployment, while expanded code analysis rules help enforce naming standards and best practices across your migrations. On the deployment front, GitHub Actions workflow generation streamlines CI/CD integration, and new Oracle deployment options add existence checks and permission validation to reduce deployment errors. Desktop's PostgreSQL filter UI now gives teams fine-grained control over object comparison, while CLI improvements like Native Connectors support for SQLite and Cassandra, Azure Key Vault integration, and better error reporting for drift resolution strengthen enterprise deployments and reduce troubleshooting time.
