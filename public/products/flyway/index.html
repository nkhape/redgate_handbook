Product Overview

Redgate Flyway

Database migrations made easy

What it does

Flyway is an open-source database migration tool that lets teams version-control their schema changes alongside application code. It applies migrations in order, tracks what's been run, and integrates with any CI/CD pipeline — so your database moves with your code, every time.

Supported Platforms

PostgreSQL
MySQL
Oracle
MariaDB

Key Features

Database Version Control

Every database change is version-controlled — written down, ordered, and tracked, just like application code. No guessing what's been applied where.

Works however you want

Either way, Flyway generates the actual deployment script for you — respecting dependencies and applying changes in the right order.

CI/CD Integration

Flyway plugs straight into the pipelines your team already uses, so migrations run automatically and identically on every deploy — no manual steps, no "works on my machine."

What's New

February 5, 2026 – June 4, 2026

Recent releases bring powerful new capabilities for database management and deployment workflows. The PostgreSQL filter UI now supports multiple rules per object type, giving you fine-grained control over comparison and deployment. Code review is now integrated directly into deployment and generation screens, surfacing potential issues before scripts run. For Oracle deployments, new options add existence checks to INSERT statements and permissions checks to GRANT/REVOKE statements, reducing deployment risk. GitHub Actions workflow generation is now available, streamlining CI/CD integration. Teams also benefit from expanded code analysis rules and Native Connectors support for SQLite and enhanced PostgreSQL/MySQL progress reporting.
