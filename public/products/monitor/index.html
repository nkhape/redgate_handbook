Product Overview

Redgate Monitor

Full visibility into your entire database estate

What it does

Redgate Monitor provides real-time monitoring and alerting for SQL Server, PostgreSQL, Oracle, MongoDB and MySQL — whether on-premise or in the cloud. It gives DBAs and ops teams a single pane of glass to catch performance issues before they impact users.

Key Features

Global Dashboard

See your entire DB estate, all on one page. No matter if SQL Server, Postgres, MongoDB, MySQL — no matter if on-premise or in the Cloud.

→ Open Global Dashboard

Server Overview Page

Timeline of everything that happened on a server, showing current and past performance and events — move the time-frame and all information gets updated. Shows which queries could be improved, and how (with or without AI). Very useful for Root Cause Analysis.

Alerts

→ Alert Inbox

All alerts that were received, across all servers.

→ Edit Alert Configuration

Change alert threshold, to avoid alert fatigue (can also be done automatically for some alerts using Machine Learning).

→ Custom Metrics

Need something specific? Collect and alert on your own metrics.

Monitor Enterprise

Data API

Send data from Monitor anywhere you need it (e.g. PowerBI to analyze).

High Availability

Ensures uninterrupted DB monitoring.

→ Permissions

Full audit of who has permissions in your estate, including historical changes.

→ Configuration Compliance

Easily benchmark which Servers / DBs are compliant, and which ones are not.

What's New

October 16, 2025 – June 10, 2026

Recent releases bring powerful monitoring enhancements across your entire database estate. SQL Agent job monitoring now supports Contained Availability Groups, while native ServiceNow and Microsoft Teams notifications streamline your alerting workflow. For cloud customers, individual query execution monitoring is now available for Azure SQL Database and Azure SQL Managed Instance, giving you deeper visibility into performance issues. The platform has also improved usability with faster load times on disk usage pages and better blocking tree visualization, plus PostgreSQL customers benefit from smarter index change detection in query plans.
