Product Overview

Redgate Test Data Manager

Safe, realistic test data on demand

What it does

Test Data Manager helps teams provision masked, compliant, and production-like data for testing — without exposing real customer data. Developers and QA engineers get the data they need, self-service, without waiting on a DBA or risking a GDPR breach.

Supported Platforms

SQL Server
Oracle

Key Features

Data Masking & Anonymisation

Replace sensitive production data with realistic synthetic values — names, emails, addresses, card numbers — while preserving the shape and referential integrity of the data. The result looks real, behaves real, and contains nothing it shouldn't.

Deterministic masking

The same input always produces the same masked output, so joins still work across tables.

Format-preserving

Masked values match the format of the original — so application validation still passes.

Custom masking rules

Define your own masking logic for domain-specific fields.

Self-Service Provisioning

Developers and testers request the data they need without raising a ticket or waiting on a DBA. Provision a fresh, masked copy of a database in minutes — not days.

On-demand clones

Spin up a masked database copy for any environment, any time.

Subsetting

Provision a representative slice of production data — not the full 10TB — keeping test environments lean and fast.

CI/CD integration

Automate data provisioning as part of your pipeline so every test run starts with clean, consistent data.

Compliance & Governance

Built for teams who need to demonstrate compliance with GDPR, HIPAA, and other data privacy regulations. Every provisioning action is logged and auditable.

GDPR-ready

No PII ever leaves production unmasked — full audit trail of what was provisioned and to whom.

Policy enforcement

Define organisation-wide masking policies that can't be bypassed by individual teams.

Data classification

Automatically detect and tag sensitive columns across your database estate.

CI/CD & Pipeline Integration

Test Data Manager fits into the pipelines you already have. Provision fresh test data automatically on every build — no manual prep, no stale snapshots.

REST API

Trigger provisioning from any pipeline tool — Jenkins, GitHub Actions, Azure DevOps, and more.

CLI

Script provisioning steps alongside your deployment automation.

Supports SQL Server and Oracle

With more databases on the roadmap.
