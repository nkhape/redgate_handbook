SQL Toolbelt Essentials

Das essenzielle Toolkit für SQL-Server-Entwickler

Was es macht

SQL Toolbelt Essentials bündelt die meistgenutzten SQL-Server-Tools von Redgate in einem Paket — Schemavergleich, Datenvergleich, intelligente Autovervollständigung und schnelle Objektsuche. Die Tools, zu denen SQL-Server-Entwickler täglich greifen, zum gebündelten Preis.

Unterstützte Plattformen

SQL Server

Hauptfunktionen

SQL Compare

Vergleichen und bereitstellen von SQL-Server-Datenbankschemas in wenigen Minuten. Sehen Sie genau, was sich zwischen zwei Datenbanken unterscheidet, generieren Sie ein Deployment-Skript und wenden Sie es an — mit vollständiger Vorschau, bevor sich etwas ändert.

Schema-Diff

Side-by-Side-Vergleich beliebiger zweier SQL-Server-Datenbanken, Skripte oder Quellcode-Ordner.

Generierung von Deployment-Skripten

Generieren Sie mit einem Klick ein sicheres, geordnetes Deployment-Skript — oder führen Sie es direkt aus.

→ Versionskontroll-Integration

Vergleichen Sie gegen einen Skriptordner in Git, um Schema und Code synchron zu halten.

SQL Data Compare

Vergleichen und synchronisieren Sie Daten zwischen SQL-Server-Datenbanken auf Zeilenebene. Finden Sie genau, welche Zeilen sich unterscheiden, und stellen Sie nur das bereit, was sich geändert hat — ideal, um Referenzdaten und Nachschlagetabellen über Umgebungen hinweg synchron zu halten.

Zeilengenauer Diff

Sehen Sie Einfügungen, Aktualisierungen und Löschungen zwischen zwei beliebigen Datenbanken.

Selektives Deployment

Wählen Sie genau, welche Zeilen synchronisiert werden — Sie behalten immer die Kontrolle.

Vergleich von Backup und Live-Datenbank

Vergleichen Sie eine Live-Datenbank mit einem Backup, um zu verstehen, was sich geändert hat.

SQL Prompt

Intelligente Autovervollständigung, Code-Formatierung und Snippet-Verwaltung für SQL Server Management Studio und Azure Data Studio. Schreiben Sie SQL schneller und mit weniger Fehlern.

Kontextbezogene Autovervollständigung

Vorschläge, die Ihr Schema verstehen — Tabellen, Spalten, Aliasnamen und mehr.

Code-Formatierung

Formatieren Sie beliebiges SQL sofort mit einem einzigen Tastenkürzel im Stil Ihres Teams.

Snippets

Speichern und wiederverwenden Sie Boilerplate-SQL — gängige Abfragen, Vorlagen und Muster.

→ SQL Prompt für VS Code

Jetzt auch als VS-Code-Erweiterung verfügbar.

SQL Search

Finden Sie jedes Datenbankobjekt — Tabellen, Spalten, gespeicherte Prozeduren, Views — serverübergreifend in Sekunden. Kostenloses SSMS-Plugin, enthalten in Toolbelt Essentials.

Suche über alle Datenbanken

Eine Suchleiste, jedes Objekt auf dem Server — kein Durchklicken des Objekt-Explorers Datenbank für Datenbank mehr nötig.

Abhängigkeiten finden

Sehen Sie, was auf ein Objekt verweist, bevor Sie es ändern oder löschen.

→ Kostenloser Download

SQL Search ist auch als eigenständiges kostenloses Tool verfügbar.
