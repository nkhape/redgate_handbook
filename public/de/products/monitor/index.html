Redgate Monitor

Volle Transparenz über Ihren gesamten Datenbankbestand

Was es macht

Redgate Monitor bietet Echtzeitüberwachung und Alarmierung für SQL Server, PostgreSQL, Oracle, MongoDB und MySQL — egal ob On-Premise oder in der Cloud. Es gibt DBAs und Ops-Teams eine zentrale Übersicht, um Performance-Probleme zu erkennen, bevor sie Nutzer beeinträchtigen.

Hauptfunktionen

Globales Dashboard

Sehen Sie Ihren gesamten Datenbankbestand auf einer einzigen Seite. Egal ob SQL Server, Postgres, MongoDB, MySQL — egal ob On-Premise oder in der Cloud.

→ Globales Dashboard öffnen

Server-Übersichtsseite

Zeitverlauf aller Ereignisse auf einem Server, mit aktueller und vergangener Performance und Events — verschieben Sie den Zeitrahmen, und alle Informationen werden aktualisiert. Zeigt, welche Abfragen verbessert werden könnten und wie (mit oder ohne KI). Sehr nützlich für die Ursachenanalyse (Root Cause Analysis).

Alarme

→ Alarm-Posteingang

Alle Alarme, die eingegangen sind, über alle Server hinweg.

→ Alarmkonfiguration bearbeiten

Alarmschwellen ändern, um Alarmmüdigkeit zu vermeiden (kann für einige Alarme auch automatisch per Machine Learning erfolgen).

→ Benutzerdefinierte Metriken

Brauchen Sie etwas Spezifisches? Erfassen und alarmieren Sie auf Basis eigener Metriken.

Monitor Enterprise

Daten-API

Senden Sie Daten aus Monitor überallhin, wo Sie sie brauchen (z. B. PowerBI zur Analyse).

Hochverfügbarkeit

Sichert eine unterbrechungsfreie Datenbanküberwachung.

→ Berechtigungen

Vollständiges Audit, wer welche Berechtigungen in Ihrem Bestand hat, inklusive Änderungshistorie.

→ Konfigurations-Compliance

Prüfen Sie leicht, welche Server/Datenbanken konform sind und welche nicht.

Neuigkeiten

17. November 2025 – 14. Oktober 2026

Aktuelle Updates bieten leistungsstarke KI-Funktionen und betriebliche Verbesserungen für Ihr Monitoring. Verbinden Sie KI-Assistenten wie Claude oder GitHub Copilot direkt mit Monitor über MCP-Server, um Fragen zur Datenbankleistung mit schreibgeschütztem Datenzugriff zu stellen. Neue Warnungstypen für wiederholte Anmeldungsfehler und Tabellenerosion auf PostgreSQL helfen dabei, Sicherheitsprobleme und Speicherprobleme früher zu erkennen. Windows PostgreSQL-Monitoring wird jetzt unterstützt und erweitert Ihre Infrastrukturabdeckung. Leistungsverbesserungen und neue Konfigurationsoptionen erleichtern die Verwaltung großer Umgebungen, während verbesserte Cloud-Kostenverfolgung und verbesserte Funktionen zur Warnungsunterdrückung Ihnen bessere Kontrolle über Ihre Monitoring-Umgebung geben.
